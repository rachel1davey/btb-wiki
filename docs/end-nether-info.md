# End & Nether Info

The End and Nether do not reset on a set schedule. End City loot returns after its chunk has been inactive for 30 days. Homes are disabled in the End so players cannot keep chunks loaded and prevent the loot from returning.

## World borders

* Overworld: 150,000 blocks
* Nether: 20,000 blocks
* End: 50,000 blocks
