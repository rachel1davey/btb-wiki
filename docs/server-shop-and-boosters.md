# Server Shop and Boosters

Use `/shop` to buy server items and Enchants Crate openings. Player shops in the Shopping District are separate.

## Boosters

Boosters increase the money or experience you earn for a limited time. The server has boosters for shop sales, job money, job experience, and Battle Pass experience. You can buy some in `/shop`. Shop money and Battle Pass experience boosters are also in the [BackToBlocks store](https://store.backtoblocks.fun).

Each booster says what it affects, its multiplier, and how long it lasts. Some help the player who activates them; others help everyone. Run `/boosters` to see unused boosters and active boosts.

## Custom enchantments

Choose Green for Common books, Red for Rare books, or Pink for Epic books. Open `/shop` to buy an opening, then use `/keys` to preview or open it. The [Custom Enchant Crates guide](custom-enchant-crates.md) has the prices and details.
